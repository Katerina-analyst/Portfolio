## UC-07. Отмена записи клиентом

**Цель:** Клиент отменяет запись по ссылке

**Основной актор:** Клиент

**Заинтересованные стороны:**
- Клиент: хочет самостоятельно отменять свои записи, чтобы не ожидать ответа от мастера

**Предусловия:**
- В системе есть запись на процедуру
- У клиента есть действительная ссылка на запись
- Время начала записи ещё не наступило

**Триггер:**
- Клиент открывает страницу записи по ссылке с access_token

**Основной сценарий:**
1. Система отображает параметры записи 
2. Клиент инициирует отмену записи
3. Система запрашивает подтверждение отмены записи
4. Клиент подтверждает отмену записи
5. Система отменяет запись
6. Связанный временной интервал снова может отображаться как доступный слот
7. Система отображает клиенту подтверждение отмены
8. Система инициирует отправку уведомления мастеру через UC-06

**Альтернативные сценарии:**

**4а. Отказ от отмены записи**
1. Клиент не подтверждает отмену записи
2. Система возвращает клиента к просмотру параметров записи

**Поток исключений:**

**1а. Срок действия ссылки истек**
1. Система сообщает клиенту, что отмена записи по ссылке уже недоступна
2. Система не изменяет данные записи

**Гарантии успеха:**
- Система отменяет запись
- Связанный временной интервал снова может отображаться как доступный слот
- Система отображает клиенту подтверждение отмены
- Система инициирует отправку уведомления мастеру

**Минимальные гарантии при неуспешном завершении:**
- Запись не отменена
- Клиент получил сообщение о невозможности отменить запись
