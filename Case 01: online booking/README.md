# Онлайн-запись к бьюти-мастеру

В репозитории представлены аналитические артефакты для MVP сайта онлайн-записи клиента на процедуру к индивидуальному бьюти-мастеру.

## 1. Описание продукта

Сайт позволяет клиентам ознакомиться с информацией о процедурах, записаться на процедуру онлайн без обязательной регистрации, получить уведомление о записи и при необходимости отменить запись по ссылке.

Мастер через личный кабинет может управлять профилем, процедурами, расписанием, записями и каналами связи.

---

## 2. Проблема

До внедрения онлайн-записи мастер ведет записи и расписание вручную: через звонки, сообщения и таблицы. Это занимает время и создает риск потери заявок, накладок в расписании и пропущенных визитов.

Клиенту неудобно записываться вручную: нужно ждать ответа мастера, нельзя самостоятельно посмотреть доступные даты и выбрать свободное время визита.

---

## 3. Цель MVP

Автоматизировать онлайн-запись клиентов на процедуры, сократить ручную работу мастера при ведении расписания и записей, а также предоставить клиентам удобный способ записи без ожидания ответа мастера.

---

## 4. Границы MVP

В MVP входит:

- онлайн-запись клиента на одну процедуру без обязательной регистрации
- просмотр и отмена записи клиентом по ссылке
- авторизация мастера в личном кабинете
- управление профилем мастера и каналами связи
- управление процедурами
- настройка расписания и недоступных периодов
- просмотр и отмена записей мастером
- формирование доступных дат и свободных слотов
- инициирование уведомлений по записи

В MVP не входит:

- регистрация клиента
- личный кабинет клиента
- онлайн-запись на несколько процедур одновременно
- выбор из нескольких мастеров или филиалов
- онлайн-оплата
- программа лояльности
- отзывы клиентов в системе
- мобильное приложение
- аналитика и отчеты
- массовые рассылки и маркетинговые акции

---

## 5. Роли пользователей

| **Роль** | **Описание** |
| -------- | ------------ |
| Клиент | Просматривает публичную информацию, записывается онлайн, получает уведомления и может отменить запись по ссылке |
| Мастер | Управляет профилем, процедурами, расписанием, записями и каналами связи |
