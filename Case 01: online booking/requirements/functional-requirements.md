# Функциональные требования

## 1. Онлайн-запись клиента на процедуру

### FRQ-01. Просмотр и выбор категорий и процедур

| **ID** | **Требование** |
| -------- | ------------ |
| FRQ-01.01 | Система должна отображать клиенту список доступных категорий процедур |
| FRQ-01.02 | Система должна позволять клиенту выбрать категорию процедур |
| FRQ-01.03 | Система должна отображать список процедур выбранной категории |
| FRQ-01.04 | Система должна отображать только процедуры, доступные для онлайн-записи |
| FRQ-01.05 | Система должна отображать клиенту название, краткое описание, стоимость и длительность выбранной процедуры |

### FRQ-02. Выбор даты и времени

| **ID** | **Требование** |
| -------- | ------------ |
| FRQ-02.01 | Система должна рассчитывать доступные даты после выбора процедуры |
| FRQ-02.02 | Система должна отображать клиенту доступные даты для выбранной процедуры |
| FRQ-02.03 | Система должна позволять клиенту выбрать доступную дату визита |
| FRQ-02.04 | Система должна рассчитывать свободные слоты после выбора доступной даты визита |
| FRQ-02.05 | Система должна отображать клиенту свободные слоты на выбранную дату |
| FRQ-02.06 | Система должна позволять клиенту выбрать свободный слот |
| FRQ-02.07 | Система должна повторно проверять доступность выбранного слота перед созданием записи |
| FRQ-02.08 | Если выбранный слот стал недоступен, система должна сообщить об этом клиенту и предложить выбрать другой свободный слот |

### FRQ-03. Ввод контактных данных

| **ID** | **Требование** |
| -------- | ------------ |
| FRQ-03.01 | Поля имени клиента и номера телефона должны быть доступны после открытия формы онлайн-записи |
| FRQ-03.02 | Система должна позволять клиенту ввести имя и номер телефона |
| FRQ-03.03 | Система не должна требовать регистрации клиента для создания записи |
| FRQ-03.04 | Система должна проверять заполнение обязательных полей формы онлайн-записи |
| FRQ-03.05 | Система должна проверять корректность имени и номера телефона |

### FRQ-04. Подтверждение записи

| **ID** | **Требование** |
| -------- | ------------ |
| FRQ-04.01 | Система должна позволять клиенту подтвердить запись после выбора категории, процедуры, доступной даты, свободного слота и корректного заполнения обязательных контактных данных |
| FRQ-04.02 | Система должна позволять клиенту редактировать параметры записи до подтверждения |
| FRQ-04.03 | Система должна позволять клиенту прервать процесс онлайн-записи до подтверждения записи |
| FRQ-04.04 | Система не должна позволять клиенту подтвердить запись, если обязательные данные заполнены некорректно, есть пустые поля или свободный слот не выбран |

### FRQ-05. Создание записи

| **ID** | **Требование** |
| -------- | ------------ |
| FRQ-05.01 | Система должна создавать запись после подтверждения клиентом формы онлайн-записи |
| FRQ-05.02 | Система должна связывать запись с клиентом, процедурой, днем расписания, датой и временем визита |
| FRQ-05.03 | После успешного создания записи система должна отображать клиенту подтверждение успешной записи |
| FRQ-05.04 | После создания записи система должна сгенерировать ссылку для просмотра и отмены записи |
| FRQ-05.05 | После создания записи система должна инициировать отправку уведомлений мастеру и клиенту через UC-06 |
| FRQ-05.06 | Если запись не удалось создать, система должна показывать клиенту понятное уведомление об ошибке и не сохранять некорректную запись |
| FRQ-05.07 | При создании записи система должна сохранять стоимость выбранной процедуры на момент создания записи |

## 2. Авторизация мастера

### FRQ-06. Вход в личный кабинет мастера

| **ID** | **Требование** |
| -------- | ------------ |
| FRQ-06.01 | Система должна отображать мастеру форму авторизации по его ссылке для входа |
| FRQ-06.02 | Система должна позволять мастеру ввести логин и пароль  |
| FRQ-06.03 | Система должна проверять корректность логина и пароля |
| FRQ-06.04 | Если логин и пароль корректны, система должна авторизовать мастера |
| FRQ-06.05 | После успешной авторизации система должна открывать личный кабинет мастера |
| FRQ-06.06 | Если логин или пароль некорректны, система должна подсветить ошибки или сообщить, что данные для входа неверные |
| FRQ-06.07 | Если превышено количество попыток входа, система должна временно ограничивать повторные попытки |
| FRQ-06.08 | Неавторизованный пользователь не должен получать доступ к личному кабинету мастера |

## 3. Управление процедурами

### FRQ-07. Управление категориими и процедурами

| **ID** | **Требование** |
| -------- | ------------ |
| FRQ-07.01 | Система должна позволять мастеру создавать процедуру |
| FRQ-07.02 | Система должна позволять мастеру редактировать или вносить название, краткое описание, стоимость, длительность и статус процедуры |
| FRQ-07.03 | Система должна позволять мастеру привязать процедуру к направлению |
| FRQ-07.04 | Процедура со статусом `available` должна отображаться клиентам |
| FRQ-07.05 | Процедура со статусом `unavailable` не должна отображаться клиентам |
| FRQ-07.06 | Система должна позволять мастеру просматривать список созданных процедур |

## 4. Настройка расписания

### FRQ-08. Управление расписанием, днями расписания и недоступными периодами

| **ID** | **Требование** |
| -------- | ------------ |
| FRQ-08.01 | Система должна позволять мастеру создавать расписание на выбранный период |
| FRQ-08.02 | Система должна позволять мастеру изменять признак рабочего дня: рабочий или нерабочий |
| FRQ-08.03 | Система должна позволять мастеру указывать время начала и окончания работы для рабочего дня |
| FRQ-08.04 | Система должна позволять мастеру добавлять недоступные периоды внутри рабочего дня |
| FRQ-08.05 | Система должна позволять мастеру изменять недоступные периоды |
| FRQ-08.06 | Система должна запрещать пересечение периодов расписания одного мастера |
| FRQ-08.07 | Система должна формировать доступные слоты по правилам, описанным в документе [Бизнес-правила](business-rules.md) |

## 5. Управление записями мастером

### FRQ-09. Просмотр и отмена записей мастером

| **ID** | **Требование** |
| -------- | ------------ |
| FRQ-09.01 | Система должна позволять мастеру просматривать календарь записей |
| FRQ-09.02 | Система должна позволять мастеру выбирать период просмотра календаря записей |
| FRQ-09.03 | Система должна позволять мастеру просматривать карточку записи |
| FRQ-09.04 | Система должна отображать в карточке записи: процедуру, длительность, стоимость, дату, время визита и контактные данные клиента |
| FRQ-09.05 | Система должна позволять мастеру отменить запись |
| FRQ-09.06 | При отмене записи система должна изменять статус записи на `canceled` |
| FRQ-09.07 | При отмене записи соответствующий временной интервал снова может отображаться как доступный слот, если это не противоречит бизнес-правилам |
| FRQ-09.08 | При отмене записи система должна отобразить мастеру подтверждение отмены |
| FRQ-09.09 | При отмене записи система должна инициировать отправку уведомления об отмене клиенту |

## 6. Уведомления

### FRQ-10. Отправка уведомлений

| **ID** | **Требование** |
| -------- | ------------ |
| FRQ-10.01 | Система должна инициировать отправку уведомления с подтверждением записи и ссылкой клиенту после создания записи |
| FRQ-10.02 | Система должна инициировать отправку уведомления о новой записи мастеру после создания записи |
| FRQ-10.03 | Система должна инициировать отправку уведомления клиенту об отмене записи мастером |
| FRQ-10.04 | Система должна инициировать отправку уведомления мастеру об отмене записи клиентом |
| FRQ-10.05 | Система должна инициировать отправку напоминания клиенту о визите за 24 часа до визита |
| FRQ-10.06 | Система должна хранить статус отправки уведомления |
| FRQ-10.07 | Система должна логировать ошибки отправки уведомлений |
| FRQ-10.08 | Если уведомление не отправлено по основному каналу, система должна зафиксировать ошибку и передать информацию мастеру или во внутренний канал |
| FRQ-10.09 | Система должна фиксировать дату и время создания уведомления |
| FRQ-10.10 | Система должна фиксировать дату и время отправки уведомления |

## 7. Отмена записи клиентом

### FRQ-11. Отмена записи клиентом по ссылке

| **ID** | **Требование** |
| -------- | ------------ |
| FRQ-11.01 | Система должна позволять клиенту отменить запись по ссылке |
| FRQ-11.02 | Система должна позволять клиенту просматривать параметры записи: процедуру, длительность, стоимость, дату, время визита |
| FRQ-11.03 | При отмене записи система должна изменять статус записи на `canceled` |
| FRQ-11.04 | При отмене записи соответствующий временной интервал снова может отображаться как доступный слот, если это не противоречит бизнес-правилам |
| FRQ-11.05 | При отмене записи система должна отобразить клиенту подтверждение отмены |
| FRQ-11.06 | При отмене записи система должна инициировать отправку уведомления об отмене мастеру |
| FRQ-11.07 | Система должна считать ссылку для просмотра и отмены записи недействительной после наступления начала времени записи |

## 8. Управление профилем мастера

### FRQ-12. Управление профилем мастера и каналами связи

| **ID** | **Требование** |
| -------- | ------------ |
| FRQ-12.01 | Система должна позволять мастеру изменить свое имя |
| FRQ-12.02 | Система должна отображать мастеру список преднастроенных типов каналов связи |
| FRQ-12.03 | Система должна позволять мастеру указать или изменить значение канала связи |
| FRQ-12.04 | Система должна позволять мастеру включить канал связи |
| FRQ-12.05 | Система должна позволять мастеру отключить канал связи |
| FRQ-12.06 | Система должна позволять мастеру выбрать канал связи по умолчанию |
| FRQ-12.07 | Система должна отображать клиенту только активные каналы связи мастера |
| FRQ-12.08 | Если канал связи отключен или значение канала не заполнено, система не должна отображать его клиенту |

## 9. Связь с мастером

### FRQ-13. Отображение каналов связи

| **ID** | **Требование** |
| -------- | ------------ |
| FRQ-13.01 | Система должна отображать клиенту активные каналы связи с мастером на главной странице сайта |
| FRQ-13.02 | Система должна отображать только активные каналы связи мастера |
| FRQ-13.03 | При выборе канала email система должна открывать создание письма на адрес мастера |
| FRQ-13.04 | При выборе канала телефона система должна открывать набор номера мастера |
| FRQ-13.05 | При выборе канала VK система должна открывать страницу мастера во VK |
| FRQ-13.06 | При выборе канала MAX система должна открывать канал связи мастера в MAX |
