# Связи сущностей

**Таблица связей**

| **Сущность 1**   | **Связь** | **Сущность 2**     | **Описание** |
| ---------------- | --------- | ------------------ | ------------ |
| Пользователь | 1:N | Запись | Один пользователь может быть связан с несколькими записями: как клиент через `client_user_id` или как мастер через `master_user_id` |
| Пользователь | 1:N | Процедура | Один мастер может создать несколько процедур |
| Тип процедуры | 1:N | Процедура | Один тип процедуры может включать несколько процедур |
| Слот | 1:0..1 | Запись | Один слот может быть свободен или связан только с одной записью |
| Пользователь | 1:N | Расписание | Один мастер может иметь несколько расписаний |
| Расписание | 1:N | Недоступный период | Одно расписание может содержать несколько недоступных периодов |
| Расписание | 1:N | Слот | На основе одного расписания может быть сформировано несколько слотов |
| Запись | N:1 | Процедура | Одна запись создаётся на одну выбранную процедуру |
| Запись | 1:N | Уведомление | По одной записи может быть создано несколько уведомлений |
| Пользователь | 1:N | Уведомление | Один пользователь может быть получателем нескольких уведомлений |
| Пользователь | 1:N | Канал связи | Один пользователь может иметь несколько каналов связи |
| Тип канала связи | 1:N | Канал связи | Один тип канала связи может использоваться в нескольких каналах связи |

**Пояснения:**

- Один слот может быть связан только с одной записью, чтобы исключить двойное бронирование
- Сущность `Пользователь` используется для клиента и мастера. Роль определяется через `user_type`
