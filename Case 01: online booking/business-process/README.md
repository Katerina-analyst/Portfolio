# Основной бизнес-процесс

**Бизнес-процесс:** Онлайн-запись клиента на процедуру

**Результат бизнес-процесса:**

- При успешном завершении клиент записан на выбранную процедуру, запись сохранена в системе, а клиенту и мастеру инициирована отправка уведомлений
- При неуспешном завершении запись не создается, выбранный временной интервал не блокируется системой, клиент оповещен о причине невозможности записи
