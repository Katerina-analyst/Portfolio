## UC-01. Онлайн-запись клиента на процедуру без регистрации

**Цель:** Клиент самостоятельно записывается на процедуру через сайт без обязательной регистрации

**Основной актор:** Клиент

**Заинтересованные стороны**
- Клиент: хочет самостоятельно записываться на процедуры онлайн
- Мастер: хочет получить корректную запись в расписании  

**Предусловия:**
- В системе есть опубликованные направления и процедуры
- Система онлайн-записи доступна
- Запись без регистрации доступна для клиента

**Триггер:** Клиент инициирует онлайн-запись на процедуру

**Основной сценарий:**
1. Система отображает форму онлайн-записи с полями: направление процедуры, процедура, дата визита, свободный слот, имя клиента и номер телефона
2. Поля выбора слота, имени и номера телефона отображаются неактивными до выбора направления, процедуры и даты визита
3. Клиент выбирает направление процедуры, процедуру и дату визита
4. Система активирует выбор слота
5. Система отображает свободные слоты на выбранную дату с учетом длительности выбранной процедуры
6. Клиент выбирает свободный слот
7. Система активирует поля для ввода имени и номера телефона
8. Клиент вводит имя и номер телефона
9. Клиент подтверждает запись
10. Система проверяет корректность заполненных данных
11. Система повторно проверяет доступность выбранного слота
12. Система сохраняет запись
13. После сохранения записи выбранный временной интервал больше не отображается другим клиентам как доступный слот
14. Система генерирует ссылку для просмотра и отмены записи
15. Система отображает клиенту подтверждение успешной записи
16. Система инициирует отправку уведомления клиенту с подтверждением записи и ссылкой для просмотра и отмены записи через UC-06
17. Система инициирует отправку уведомления мастеру о новой записи через UC-06

**Альтернативные сценарии:**

**5а. Нет свободных слотов на выбранную дату**

1. Система сообщает, что на выбранную дату нет свободных слотов
2. Система предлагает выбрать другую дату
3. Продолжение основного сценария с шага 3

**10а. Поля формы заполнены некорректно**

1. Система подсвечивает поля с ошибками
2. Система сообщает причину ошибки
3. Клиент исправляет данные
4. Продолжение основного сценария с шага 8

**11а. Выбранный слот стал недоступен**

1. Система сообщает, что выбранный временной интервал больше недоступен для записи
2. Система предлагает выбрать другой свободный слот
3. Продолжение основного сценария с шага 5

**Поток исключений:**

**12а. Ошибка создания записи**

1. Система сообщает клиенту, что запись не удалось создать
2. Система не сохраняет запись
3. Выбранный временной интервал не исключается из списка доступных слотов, если по нему не была создана другая активная запись
4. Система предлагает альтернативный способ записи

**Гарантии успеха:**

- Запись сохранена в системе
- Выбранный временной интервал больше не отображается другим клиентам как доступный слот
- Система сгенерировала ссылку для просмотра и отмены записи клиентом
- Клиент видит подтверждение успешной записи
- Система инициировала отправку уведомлений клиенту и мастеру через UC-06

**Минимальные гарантии при неуспешном завершении:**

- Запись не создана
- Выбранный временной интервал не блокируется системой, если запись не была создана
- Клиент получил сообщение о невозможности создать запись при ошибке создания записи
