## Краткое описание `schema.sql`

Файл `schema.sql` описывает физическую модель базы данных для MVP.

В схему входят таблицы для хранения:

- пользователей
- категорий процедур
- процедур
- расписания мастера
- дней расписания
- недоступных периодов
- записей клиентов
- уведомлений
- типов каналов связи
- каналов связи пользователей

Описание логической модели данных находится в разделе [Модель данных](../data-model).
