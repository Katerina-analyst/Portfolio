Названия полей в БД используются в формате `snake_case`.

Названия параметров в JSON используются в формате `camelCase`.

При формировании ответа Backend преобразует названия полей БД в названия параметров API согласно таблице маппинга.

Внутренние коды ошибок определяются разработчиком при реализации единого формата обработки ошибок.
