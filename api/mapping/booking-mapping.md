## 1. Описание и маппинг API-методов процесса онлайн-записи

### Метод: Получение списка категорий процедур
**HTTP-метод:** `GET`
**URL:** `/public/v1/procedure-categories`
**Идемпотентность:** метод является идемпотентным и не изменяет данные в системе
**Назначение:** возвращает список категорий процедур, отсортированный по названию в алфавитном порядке
**Доступность:** метод публичный, вызывает любой пользователь без авторизации. Bearer token не нужен
**Headers:** `Accept: application/json`

**Успешный ответ:**

**Статус-код ответа:** 200 ОК 

**Описание:** список категорий процедур успешно получен

**Тело ответа:**

```json
[
    {
        "categoryId": 2,
        "categoryName": "Аппаратная и эстетическая косметология"
    },
    {
        "categoryId": 1,
        "categoryName": "Инъекционная косметология"
    },
    {
        "categoryId": 4,
        "categoryName": "Консультации"
    },
    {
        "categoryId": 3,
        "categoryName": "Перманентный макияж"
    }
]
```

**Маппинг ответа:**

| **Поле на фронте** | **Поле в JSON** | **Поле в БД** | **Таблица в БД** | **Комментарий** |
|---|---|---|---|---|
| Не отображается, используется для последующих запросов | `categoryId` | `id` | `procedure_categories` | Первичный ключ категории процедур |
| Название категории | `categoryName `| `category_name` | `procedure_categories` | Название параметра преобразуется из snake_case в camelCase |

**Статус-код ошибки:** 500 Internal Server Error

**Причина:** непредвиденная ошибка Backend или ошибка при обращении к БД

**Тело ответа**
```json
    {
        "code": 500,
        "message": "Внутренняя ошибка сервера"
    }
```
