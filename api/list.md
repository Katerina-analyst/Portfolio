# Список REST API-методов

## 1. Назначение документа

Документ содержит перечень REST API-методов, необходимых для реализации онлайн-записи клиентов и личного кабинета мастера.
Методы сгруппированы в соответствии с документами:[функциональных требований](../requirements/functional-requirements.md) и [матрицы трассировки](../requirements/traceability-matrix.md).
Подробное описание запросов, ответов, бизнес-правил, ошибок, алгоритмов работы и маппинга данных приводится в документации соответствующих REST API-методов.
