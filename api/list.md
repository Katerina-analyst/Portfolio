# Список REST API-методов

## 1. Назначение документа

Документ содержит перечень REST API-методов, необходимых для реализации онлайн-записи клиентов и личного кабинета мастера.
Методы сгруппированы в соответствии с документами:[функциональных требований](../requirements/functional-requirements.md) и [матрицы трассировки](../requirements/traceability-matrix.md).
Подробное описание запросов, ответов, бизнес-правил, ошибок, алгоритмов работы и маппинга данных приводится в документации соответствующих REST API-методов.

## 8. FRQ-11. Создание и отправка уведомлений

Уведомления создаются и отправляются backend-системой автоматически. Клиент и мастер не вызывают отдельные REST API-методы уведомлений.

### 8.1. После создания записи

Система должна:

1. создать уведомление клиенту;
2. создать уведомление мастеру;
3. передать уведомления на отправку через соответствующие внешние сервисы.

### 8.2. После отмены записи клиентом

Система должна:

1. создать уведомление мастеру;
2. передать уведомление на отправку по активному каналу связи мастера, выбранному по умолчанию.

### 8.3. После отмены записи мастером

Система должна:

1. создать уведомление клиенту;
2. передать уведомление на отправку по номеру телефона клиента.

### 8.4. Напоминание о визите

За 24 часа до начала активной записи система должна:

1. найти запись со статусом `created`;
2. проверить, что напоминание ранее не отправлялось;
3. создать уведомление клиенту;
4. передать уведомление на отправку.

Ошибка отправки уведомления не должна отменять создание или отмену записи.

## 11. Интеграции с внешними сервисами

Backend Beauty Bliss должен использовать внешние сервисы для отправки уведомлений.

Для уведомлений клиента по номеру телефона используется SMS-провайдер.

Способ отправки уведомлений мастеру зависит от активного канала связи, выбранного мастером по умолчанию:

- `phone` — SMS-провайдер;
- `email` — сервис отправки электронной почты;
- `vk` — API ВКонтакте;
- `max` — API MAX.

Конкретные методы, параметры авторизации, форматы запросов, ответы и ошибки определяются после выбора соответствующих внешних сервисов и получения их API-документации.
