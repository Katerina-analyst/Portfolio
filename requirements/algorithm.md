# ALG-01. Формирование свободных слотов

**Назначение:** определить свободные временные слоты для выбранной клиентом процедуры и даты визита.

**Входные данные:**

- выбранная процедура
- длительность выбранной процедуры
- выбранная дата
- день расписания на выбранную дату
- рабочий интервал дня расписания
- недоступные периоды дня расписания
- активные записи на выбранную дату

**Результат:**

- отсортированный по времени начала список свободных слотов
- пустой список, если свободные слоты отсутствуют

## Алгоритм

1. Система определяет день расписания для выбранной даты
2. Если день расписания не найден или является нерабочим, система возвращает пустой список свободных слотов
3. Система получает время начала и окончания рабочего дня
4. Система получает недоступные периоды выбранного дня расписания
5. Система получает временные интервалы активных записей на выбранную дату
6. Система исключает из рабочего интервала:
   - недоступные периоды
   - временные интервалы активных записей
7. В результате система формирует список свободных временных интервалов
8. Для каждого свободного временного интервала система выполняет следующие действия:
   1. Проверяет, что длительность свободного интервала не меньше длительности выбранной процедуры
   2. Устанавливает время начала первого слота равным времени начала свободного интервала
   3. Рассчитывает время окончания слота как сумму времени начала слота и длительности выбранной процедуры
   4. Если время окончания слота не выходит за границы свободного интервала, система добавляет слот в список свободных слотов
   5. Устанавливает время начала следующего слота равным времени окончания предыдущего слота
   6. Повторяет шаги 8.3–8.5, пока очередной слот полностью помещается в свободный интервал
9. Система объединяет слоты, сформированные для всех свободных временных интервалов
10. Система сортирует свободные слоты по времени начала по возрастанию
11. Система возвращает сформированный список свободных слотов
