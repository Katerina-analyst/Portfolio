## Глоссарий

| **Термин** | **Определение** |
|---|---|
| **Клиент** | Пользователь сайта, который может оформить запись на процедуры косметолога без регистрации и авторизации |
| **Косметолог** | Специалист, оказывающий процедуры и управляющий расписанием, каталогом процедур и записями через личный кабинет. В MVP предусмотрен один косметолог |
| **Процедура** | Услуга косметолога с установленными названием, длительностью, стоимостью и статусом доступности |
| **Визит** | Посещение косметолога клиентом для прохождения одной или нескольких выбранных процедур |
| **Запись** | Сохранённая в системе информация о запланированном визите клиента с указанием даты, времени и выбранных процедур |
| **Активная запись** | Созданная запись, которая не отменена, не выполнена и время начала которой еще не вышло |
| **Выполненная процедура** | Процедура, фактически оказанная косметологом клиенту в рамках состоявшегося визита |
| **Неявка клиента** | Отсутствие клиента на запланированном визите, которое косметолог может зафиксировать вручную, изменив статус записи на неявку. Фиксация неявки не является обязательной. |
| **Рабочий интервал** | Время между началом и окончанием рабочего дня косметолога, установленное в расписании |
| **Недоступный период** | Временной интервал внутри рабочего дня, в течение которого косметолог не принимает клиентов |
| **Свободный интервал** | Часть рабочего интервала, доступная для записи с учётом периодов недоступности, существующих активных записей и времени подготовки кабинета |
| **Временной слот** | Рассчитанный системой вариант времени начала визита, в который можно выполнить все выбранные процедуры с соблюдением правил доступности. Слоты формируются динамически и не хранятся в БД |
| **Время подготовки кабинета** | Обязательный интервал не менее 20 минут между окончанием одного визита и началом следующего |
| **Токен доступа к записи** | Уникальное значение, используемое для просмотра и отмены конкретной записи клиентом без авторизации |
