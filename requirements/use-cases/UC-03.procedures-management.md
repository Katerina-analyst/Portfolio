## UC-03. Управление процедурами косметолога

**Цель:** Косметолог создает и редактирует процедуры, которые доступны клиенту в каталоге и сценарии онлайн-записи

**Основной актор:** Косметолог

**Заинтересованные стороны:**
- Косметолог: хочет редактировать перечень процедур, которые он оказывает
- Клиент: хочет получать актуальный список процедур

**Предусловия:**
- Косметолог находится в личном кабинете
- У косметолога есть доступ к разделу управления процедурами
- Система доступна

**Триггер:** Косметолог перешел в раздел управления процедурами в личном кабинете

**Основной сценарий:**
1. Система отображает раздел управления процедурами
2. Система отображает список процедур косметолога
3. Косметолог инициирует создание новой процедуры
4. Система отображает форму создания процедуры
5. Косметолог заполняет данные процедуры: категорию из справочника, название, описание, стоимость, длительность и статус доступности для записи
6. Косметолог сохраняет процедуру
7. Система подтверждает корректность заполненных данных
8. Система сохраняет новую процедуру
9. Система отображает косметологу сообщение об успешном создании процедуры

**Альтернативные сценарии:**

**3а. Косметолог инициирует редактирование существующей процедуры**
1. Косметолог выбирает существующую процедуру из списка
2. Система отображает карточку выбранной процедуры
3. Косметолог изменяет данные процедуры: категорию, название, описание, стоимость, длительность или статус
4. Косметолог сохраняет изменения
5. Система подтверждает корректность измененных данных
6. Система сохраняет обновленную карточку процедуры
7. Система отображает косметологу сообщение об успешном обновлении процедуры

3а.5. Данные процедуры при редактировании заполнены некорректно**
1. Система подсвечивает поля с ошибками
2. Система сообщает причину ошибки
3. Косметолог исправляет данные
4. Продолжение альтернативного сценария 3А с шага 4

**7а. Данные процедуры при создании заполнены некорректно**
1. Система подсвечивает поля с ошибками
2. Система сообщает причину ошибки
3. Косметолог исправляет данные
4. Продолжение основного сценария с шага 6

**Поток исключений:**

**8а. Ошибка сохранения процедуры**
1. Система сообщает косметологу, что процедуру не удалось сохранить
2. Система не применяет изменения
3. Система логирует ошибку
4. Система предлагает повторить попытку позже

**Гарантии успеха:**
- При создании: новая процедура отображается в списке процедур косметолога
- При редактировании: обновленные данные процедуры сохранены

**Минимальные гарантии:**
- Изменения не сохранены
- Косметолог получил сообщение о невозможности сохранить процедуру
