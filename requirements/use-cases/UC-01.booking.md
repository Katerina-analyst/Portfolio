## UC-01. Онлайн-запись клиента на процедуру без регистрации

**Цель:** Клиент самостоятельно записывается на процедуру через сайт без обязательной регистрации

**Основной актор:** Клиент

**Заинтересованные стороны**
- Клиент: хочет самостоятельно записываться на процедуры онлайн и видеть только доступные даты и время
- Мастер: хочет получить корректную запись в расписании

**Предусловия:**
- В системе есть опубликованные категории процедур и процедуры
- Система онлайн-записи доступна
- Запись без регистрации доступна для клиента
- У мастера настроено расписание

**Триггер:** Клиент инициирует онлайн-запись на процедуру

**Основной сценарий:**

1. Система отображает форму онлайн-записи с полями: имя клиента, номер телефона, категория процедуры, процедура, дата визита и свободный слот
2. Поля имени клиента, номера телефона, категории процедуры доступны для заполнения
3. Клиент вводит имя и номер телефона
4. Система подтверждает корректность имени и номера телефона при вводе
5. Клиент выбирает категорию процедуры
6. Система отображает доступные процедуры после выбора категории
7. Клиент выбирает процедуру
8. Система рассчитывает доступные даты с учетом расписания мастера, недоступных периодов, активных записей и длительности выбранной процедуры
9. Система отображает клиенту доступные даты для выбранной процедуры
10. Клиент выбирает доступную дату визита
11. Система рассчитывает свободные слоты на выбранную дату с учетом длительности выбранной процедуры
12. Система отображает свободные слоты на выбранную дату
13. Клиент выбирает свободный слот
14. Система отображает чекбокс согласия на обработку персональных данных
15. Клиент дает согласие
16. Система делает подтверждение записи доступным
17. Клиент подтверждает запись
18. Система повторно подтверждает доступность выбранного слота
19. Система создает запись
20. Система генерирует токен доступа к записи и формирует ссылку для просмотра и отмены записи
21. Система отображает клиенту подтверждение успешной записи
22. Система инициирует отправку уведомления клиенту с подтверждением записи и ссылкой для просмотра и отмены записи через UC-06
23. Система инициирует отправку уведомления мастеру о новой записи через UC-06

**Альтернативные сценарии:**

**9а. Нет доступных дат для выбранной процедуры**

1. Система сообщает, что для выбранной процедуры нет доступных дат
2. Система предлагает выбрать другую процедуру или связаться с мастером
3. Подтверждение записи остается неактивным
4. Продолжение основного сценария с шага 7

**12а. Нет свободных слотов на выбранную дату**

1. Система сообщает, что на выбранную дату нет свободных слотов
2. Система предлагает выбрать другую доступную дату
3. Подтверждение записи остается неактивным
4. Продолжение основного сценария с шага 9

**16а. Не заполнены обязательные поля или заполнены некорректно**

1. Система подсвечивает поле с ошибкой
2. Система отображает причину ошибки рядом с некорректным полем
3. Подтверждение записи остается недоступным
4. Клиент вносит или исправляет данные
5. Продолжение основного сценария с шага 16

**18а. Выбранный слот стал недоступен**

1. Система сообщает, что выбранный временной интервал больше недоступен для записи
2. Система предлагает выбрать другой свободный слот
3. Подтверждение записи становится недоступным до выбора нового свободного слота
4. Продолжение основного сценария с шага 12

**Поток исключений:**

**19а. Ошибка создания записи**

1. Система сообщает клиенту, что запись не удалось создать
2. Система не сохраняет запись
3. Выбранный временной интервал не блокируется системой, если запись не была создана
4. Система предлагает альтернативный способ записи

**Гарантии успеха:**

- Запись сохранена в системе
- Выбранный временной интервал больше не отображается другим клиентам как доступный слот
- Система сгенерировала ссылку для просмотра и отмены записи клиентом
- Клиент видит подтверждение успешной записи
- Система инициировала отправку уведомлений клиенту и мастеру через UC-06

**Минимальные гарантии при неуспешном завершении:**

- Запись не создана
- Выбранный временной интервал не блокируется системой, если запись не была создана
- Клиент получил сообщение о невозможности создать запись при ошибке создания записи
