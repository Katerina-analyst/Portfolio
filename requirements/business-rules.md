# Каталог бизнес-правил

В каталоге бизнес-правила классифицируются по пяти типам:

- **Факты** - верные утверждения о бизнесе на определённый момент времени, описывающие связи и отношения между важными бизнес-терминами
- **Ограничения** - правила, определяющие, какие действия или операции запрещены, обязательны либо доступны только при выполнении установленных условий
- **Активаторы операций** - правила, которые при наступлении определённого события или выполнении определённого условия инициируют выполнение действия
- **Выводы** - правила, на основании известных фактов создающие новый производный факт. Обычно записываются в формате "если - то", где результатом является факт, а не действие
- **Вычисления** - правила, преобразующие существующие данные в новую информацию с использованием математических формул или алгоритмов

## Правила формирования слотов
| **Идентификатор** | **Определение правила** | **Тип правила** |
|---|---|---|
| BR-SLOT-01 | Слоты формируются только для рабочего дня расписания | Ограничение |
| BR-SLOT-02 | Слот должен полностью находиться внутри рабочего интервала дня расписания | Ограничение |
| BR-SLOT-03 | Слот не должен пересекаться с недоступным периодом дня расписания | Ограничение |
| BR-SLOT-04 | Слот не должен пересекаться с временным интервалом активной записи | Ограничение |
| BR-SLOT-05 | Время окончания слота вычисляется как сумма времени начала слота и продолжительности выбранной процедуры | Вычисление |
| BR-SLOT-06 | Если процедура не помещается полностью в свободный интервал, такой интервал не считается доступным слотом | Вывод |
| BR-SLOT-07 | Первый слот свободного временного интервала начинается со времени начала этого интервала | Вычисление |
| BR-SLOT-08 | Время начала каждого следующего слота равно времени окончания предыдущего слота | Вычисление |

## Правила онлайн-записи
| **Идентификатор** | **Определение правила** | **Тип правила** |
|---|---|---|
| BR-BOOKING-01 | Запись может быть создана только после подтверждения клиентом | Ограничение |
| BR-BOOKING-02 | Запись может быть создана только для доступного слота | Ограничение |
| BR-BOOKING-03 | Временные интервалы активных записей не должны пересекаться | Ограничение |
| BR-BOOKING-04 | Каждая запись должна иметь уникальный токен доступа | Ограничение |
| BR-BOOKING-05 | Просмотр и отмена записи клиентом допускаются только по уникальному токену доступа | Ограничение |
| BR-BOOKING-06 | Фиксированная стоимость определяется по цене процедуры на момент записи | Вычисление |
| BR-BOOKING-07 | Для подтверждения записи клиент должен корректно заполнить имя и номер телефона | Ограничение |
| BR-BOOKING-08 | Для подтверждения записи клиент должен выбрать категорию, процедуру, доступную дату и свободный слот | Ограничение |
| BR-BOOKING-09 | Для подтверждения записи клиент должен дать согласие на обработку персональных данных | Ограничение |

## Правила управления процедурами и категориями процедур
| **Идентификатор** | **Определение правила** | **Тип правила** |
|---|---|---|
| BR-PROCEDURE-01 | Для онлайн-записи доступны только процедуры со статусом `available` | Факт |
| BR-PROCEDURE-02 | В MVP косметолог может выбирать категории процедур только из преднастроенного справочника | Ограничение |
| BR-PROCEDURE-03 | В MVP косметолог не может создавать новые категории процедур | Ограничение |
| BR-PROCEDURE-04 | Косметолог может изменять категорию, статус, название, описание, стоимость и длительность процедуры | Ограничение |

## Правила статусов и отмены записей

|**Идентификатор**|**Определение правила**|**Тип правила**|
|---|---|---|
| BR-CANCEL-01 | При отмене записи ее статус изменяется на `canceled` | Активатор операции |
| BR-CANCEL-02 | После отмены записи ее временной интервал может снова считаться доступным, если соблюдены правила формирования слотов | Вывод |
| BR-CANCEL-03 | После наступления времени начала записи клиент не может отменить ее по ссылке | Ограничение |
| BR-CANCEL-04 | Отмененная запись не считается активной |  Вывод |
| BR-CANCEL-05 | После наступления времени начала записи отмена записи косметологом недоступна | Ограничение |
| BR-STATUS-01 | После наступления времени окончания записи со статусом `created` ее статус автоматически изменяется на `completed` | Активатор операции |
| BR-STATUS-02 | Косметолог может установить статус `no_show` только для записи со статусом `created` или `completed` после наступления времени начала записи | Ограничение |

## Правила уведомлений
| **Идентификатор** | **Определение правила** | **Тип правила** |
|---|---|---|
| BR-NOTIFY-01 | После создания записи должны быть инициированы уведомления клиенту и косметологу | Активатор операции |
| BR-NOTIFY-02 | Если запись отменил косметолог, должно быть инициировано уведомление клиенту | Активатор операции |
| BR-NOTIFY-03 | Если запись отменил клиент, должно быть инициировано уведомление косметологу | Активатор операции |
| BR-NOTIFY-04 | За 24 часа до времени начала активной записи должно быть инициировано напоминание клиенту | Активатор операции |
| BR-NOTIFY-05 | Если уведомление не отправлено, должна быть зафиксирована ошибка отправки | Активатор операции |
| BR-NOTIFY-06 | Ошибка отправки уведомления не изменяет статус созданной или отмененной записи | Ограничение |

## Правила каналов связи
| **Идентификатор** | **Определение правила** | **Тип правила** |
|---|---|---|
| BR-CHANNEL-01 | В MVP для клиента доступен только канал связи типа `phone` | Ограничение |
| BR-CHANNEL-02 | В MVP косметолог не может создавать новые типы каналов связи | Ограничение |
| BR-CHANNEL-03 | Косметолог может выбирать тип канала связи только из преднастроенного справочника | Ограничение |
| BR-CHANNEL-04 | Косметолог может изменять значение и статус отображения канала связи | Ограничение |
| BR-CHANNEL-05 | Клиенту отображаются только активные каналы связи косметолога с заполненным значением | Ограничение |
| BR-CHANNEL-06 | У косметолога может быть не более одного канала связи каждого типа | Ограничение |

## Правила пользователей, регистрации и доступа
| **Идентификатор** | **Определение правила** | **Тип правила** |
|---|---|---|
| BR-USER-01 | В MVP клиент не проходит регистрацию и не имеет личного кабинета | Ограничение |
| BR-USER-02 | Для одного клиента хранится одна запись с именем, номером телефона и `user_type = client` | Факт |
| BR-USER-03 | Если клиент с указанным номером телефона уже существует, новая запись о клиенте не создается | Ограничение |
| BR-USER-04 | Если клиент с указанным номером телефона не найден, создается запись с `user_type = client` | Активатор операции |
| BR-USER-05 | Косметолог имеет заранее созданную учетную запись с `user_type = master` | Факт |
| BR-USER-06 | Доступ к личному кабинету косметолога разрешен только авторизованному косметологу | Ограничение |
| BR-USER-07 | В MVP самостоятельное восстановление пароля косметолога недоступно | Ограничение |
| BR-USER-08 | После 3 последовательных неуспешных попыток авторизации вход в учетную запись косметолога блокируется на 60 минут | Ограничение |
| BR-USER-09 | Во время временной блокировки косметолог может дождаться окончания 60 минут либо обратиться к администратору системы для восстановления доступа | Ограничение |

## Правила настройки расписания
| **Идентификатор** | **Определение правила** | **Тип правила** |
|---|---|---|
| BR-SCHEDULE-01 | Для рабочего дня расписания косметолог должен указать время начала и окончания работы | Ограничение |
| BR-SCHEDULE-02 | Для нерабочего дня время начала и окончания работы не учитывается | Ограничение |
| BR-SCHEDULE-03 | Дата считается доступной для онлайн-записи, если день расписания является рабочим и на эту дату имеется хотя бы один доступный слот | Вывод |
| BR-SCHEDULE-04 | Периоды расписаний одного косметолога не должны пересекаться между собой | Ограничение |
| BR-SCHEDULE-05 | Недоступный период должен полностью находиться внутри рабочего интервала дня расписания | Ограничение |
| BR-SCHEDULE-06 | Недоступные периоды одного дня расписания не должны пересекаться | Ограничение |
| BR-SCHEDULE-07 | Изменение рабочего интервала дня расписания, создание или изменение недоступного периода не должны приводить к пересечению с активными записями | Ограничение |
