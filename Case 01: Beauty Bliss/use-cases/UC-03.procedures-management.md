## UC-03. Управление процедурами

**Цель:** Мастер создает и редактирует процедуры, которые отображаются на главной странице и в сценарии онлайн-записи клиента

**Основной актор:** Мастер

**Заинтересованные стороны:**
- Мастер: хочет редактировать перечень процедур, которые он оказывает
- Клиент: хочет получать актуальный список процедур

**Предусловия:**
- Мастер находится в личном кабинете
- У мастера есть доступ к разделу управления процедурами
- Система доступна

**Триггер:** Мастер перешел в раздел управления процедурами в личном кабинете

**Основной сценарий:**
1. Система отображает раздел управления процедурами
2. Система отображает список процедур мастера
3. Мастер инициирует создание новой процедуры
4. Система отображает форму создания процедуры
5. Мастер заполняет данные процедуры: направление, название, описание, стоимость, длительность и статус доступности для записи
6. Мастер сохраняет процедуру
7. Система подтверждает корректность заполненных данных
8. Система сохраняет новую процедуру
9. Система отображает мастеру сообщение об успешном создании процедуры

**Альтернативные сценарии:**

**3А. Мастер инициирует редактирование существующей процедуры**
1. Мастер выбирает существующую процедуру из списка
2. Система отображает карточку выбранной процедуры
3. Мастер изменяет данные процедуры: направление, название, описание, стоимость, длительность или статус
4. Мастер сохраняет изменения
5. Система подтверждает корректность измененных данных
6. Если статус процедуры изменен на “Недоступна для записи”, система запрашивает подтверждение изменения статуса
7. Мастер подтверждает изменение статуса, если требуется
8. Система сохраняет обновленную карточку процедуры
9. Система отображает мастеру сообщение об успешном обновлении процедуры

3А.5А. Система не подтверждает корректность данных процедуры при редактировании
1. Система подсвечивает поля с ошибками
2. Система сообщает причину ошибки
3. Мастер исправляет данные
4. Продолжение альтернативного сценария 3А с шага 4

3А.7А. Мастер не подтверждает изменение статуса процедуры
1. Мастер отказывается от изменения статуса
2. Система не сохраняет изменение статуса процедуры
3. Система возвращает мастера к карточке процедуры

**7А. Система не подтверждает корректность данных процедуры при создании**
1. Система подсвечивает поля с ошибками
2. Система сообщает причину ошибки
3. Мастер исправляет данные
4. Продолжение основного сценария с шага 6

**Поток исключений:**

**8А. Ошибка сохранения процедуры**
1. Система сообщает мастеру, что процедуру не удалось сохранить
2. Система не применяет изменения
3. Система логирует ошибку
4. Система предлагает повторить попытку позже

**Гарантии успеха:**
- Новая процедура отображается в списке процедур мастера
- Обновленные данные процедуры сохранены в системе
- Процедуры со статусом “Доступна для записи” отображаются клиенту в каталоге процедур и сценарии онлайн-записи
- Процедуры со статусом “Недоступна для записи” не отображаются клиенту в каталоге процедур и сценарии онлайн-записи

**Минимальные гарантии при неуспешном завершении:**
- Изменения не сохранены
- Мастер получил сообщение о невозможности сохранить процедуру
