## UC-01. Онлайн-запись клиента на услугу без регистрации

**Цель:** Клиент самостоятельно записывается на услугу через сайт Beauty Bliss без обязательной регистрации

**Основной актор:** Клиент

**Заинтересованные стороны**

- Клиент: хочет быстро и самостоятельно выбрать услугу, дату и время визита, забронировать время визита
- Мастер: хочет получить корректную запись в расписании
- Система: должна проверить доступность слота и сохранить запись

**Триггер:** Клиент инициирует онлайн-запись на услугу

**Предусловия:**

- Клиент открыл сайт Beauty Bliss.
- В системе есть опубликованные категории услуг и услуги.
- Для выбранной услуги есть доступные даты и временные слоты.

**Основной сценарий:**

1. Система отображает список категорий услуг
2. Клиент выбирает категорию услуги
3. Система отображает список услуг в выбранной категории
4. Клиент выбирает конкретную услугу
5. Система отображает доступные даты для выбранной услуги
6. Клиент выбирает дату визита
7. Система отображает свободные временные слоты на выбранную дату
8. Клиент выбирает временной слот
9. Система подтверждает доступность слота и временно резервирует выбранный слот
10. Система отображает экран проверки данных о записи
11. Клиент подтверждает выбранные параметры записи
12. Система отображает форму контактных данных
13. Клиент вводит имя и номер телефона
14. Клиент отправляет данные для создания записи
15. Система создаёт запись
16. Система отображает клиенту подтверждение успешной записи
17. Система инициирует отправку уведомления клиенту и мастеру (Include UC-10)

**Альтернативные сценарии:**

**А. Клиент отменяет процесс записи до создания записи**

1. Клиент инициирует отмену процесса записи или закрывает форму записи
2. Система освобождает временно-забронированный слот, если он был зарезервирован
3. Система не создаёт запись
4. Система возвращает клиента на главную страницу или предыдущий доступный экран

**3А.** В списке нет подходящей категории или услуги

1. Клиент не находит нужную категорию или услугу
2. Клиент отменяет процесс записи или переходит к альтернативному способу связи

**7А.** В списке нет подходящих слотов на выбранную дату

1. Система сообщает, что на выбранную дату нет свободных слотов
2. Система предлагает выбрать другую дату
3. Продолжение основного сценария с шага 5

**9А.** Система не подтверждает доступность слота

1. Система сообщает, что выбранный слот уже занят
2. Система предлагает выбрать другой слот
3. Продолжение основного сценария с шага 7

**13А.** Контактные данные заполнены некорректно

1. Система подсвечивает поля с ошибками
2. Клиент исправляет данные
3. Продолжение основного сценария с шага 14

**14А.** Клиент редактирует запись

1. Клиент инициирует редактирование выбранных параметров записи
2. Система освобождает временно-забронированный слот
3. Возврат к шагу 7 основного сценария

**15А.** Ошибка сохранения записи

1. Система сообщает клиенту, что запись не удалось создать
2. Система не сохраняет запись
3. Система освобождает временно-забронированный слот
4. Система возвращает клиента на главную страницу или предлагает альтернативный способ связи

**Постусловия**

- Запись создана в системе
- Выбранный слот стал недоступен для других клиентов
- Клиент видит подтверждение успешной записи
- Система инициировала отправку уведомлений клиенту и мастеру через UC-10
