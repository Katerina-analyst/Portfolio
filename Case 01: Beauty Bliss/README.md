# Beauty Bliss — сайт бьюти-мастера с онлайн-записью

## 1. Описание продукта

Beauty Bliss — веб-сайт для бьюти-мастера, который позволяет клиентам ознакомиться с услугами, ценами, отзывами и записаться на консультацию или процедуру онлайн.

Проект разрабатывается как реальный MVP для кабинета инъекционной и эстетической косметологии. На первом этапе подготовлен прототип главной страницы, далее планируется проработка каталога услуг, цен, FAQ и сценария онлайн-записи.

Целевая версия продукта должна позволять мастеру управлять услугами, расписанием, записями, клиентами и уведомлениями, а клиенту — самостоятельно выбирать услугу, дату, свободное время и управлять своими записями.

## 2. Проблемы стейкхолдеров

**Проблемы мастера**

1. Запись клиентов ведётся вручную: через звонки, мессенджеры, личные сообщения или при личном визите.

**Последствия:**
   - мастер тратит время на согласование даты и времени
   - мастер не всегда может ответить клиенту сразу
   - есть риск потерять заявку или забыть внести запись в календарь

2. Расписание ведётся вручную: в обычном календаре, блокноте или таблице

**Последствия:**
   - возможны накладки в расписании
   - сложно быстро проверить свободные окна
   - мастер может забыть отправить клиенту напоминание о визите

**Проблемы клиента**

1. Клиенту неудобно записываться вручную

**Последствия:**
   - нужно ждать ответа мастера
   - свободное время нельзя посмотреть самостоятельно
   - запись может затянуться из-за переписки

2. Клиент может забыть дату или время визита

**Последствия:**
   - это приводит к пропущенным визитам
   - нарушается расписание мастера
   - снижается качество клиентского сервиса

## 3. Цели продукта

1. Сократить ручную работу мастера при записи клиентов
2. Предоставить клиенту удобный онлайн-сервис для выбора услуги и времени визита
3. Уменьшить количество накладок и ошибок в расписании
4. Снизить количество пропущенных визитов за счёт уведомлений
5. Повысить качество обслуживания клиентов
6. Создать единую точку входа, где клиент может посмотреть услуги, цены, отзывы, FAQ и перейти к записи

## 4. Границы MVP

### В MVP входит:

**Функционал мастера:**

- регистрация
- авторизация
- создание и редактирование профиля
- создание, редактирование и удаление услуг
- настройка рабочего расписания
- просмотр календаря записей
- получение уведомлений о новой/отменённой записи
- просмотр карточки клиента

**Функционал клиента:**

- регистрация и авторизация для доступа к личному кабинету
- отмена и просмотр своих записей
- просмотр личного кабинета, его редактирование и удаление
- просмотр профиля мастера
- просмотр списка категорий услуг
- просмотр списка услуг
- просмотр страницы с ценами на услуги
- просмотр свободных дат и слотов для визита
- онлайн-запись на услугу без обязательной регистрации
- получение уведомлений о записи и отмене

**Функционал системы:**
- проверка доступности даты и временного слота перед созданием записи
- запрет двойной записи на один и тот же слот
- создание записи после подтверждения клиентом
- отправка уведомлений мастеру и клиенту
- изменение статуса записи при создании/отмене
- проверка отсутствия существующего аккаунта клиента при регистрации
- проверка корректности логина и пароля при авторизации
- валидация обязательных полей при регистрации и создании записи

### В MVP не входит

- онлайн-оплата
- программа лояльности
- отзывы и рейтинги внутри личного кабинета
- маркетплейс мастеров
- мобильное приложение
- интеграция с внешними календарями
- интеграция с CRM
- сложная аналитика и отчёты
- массовые рассылки и маркетинговые акции

## 5. Стейкхолдеры и роли

**Стейкхолдеры**

| **Стейкхолдер** | **Интерес** |
|---|---|
| Заказчик | Получить сайт и MVP онлайн-записи для продвижения услуг и автоматизации записи клиентов |
| Мастер | Управлять услугами, расписанием, записями и клиентами в одном месте |
| Клиент | Быстро посмотреть услуги, цены, свободное время, записаться онлайн без регистрации, просмотреть свои записи или отменить их после регистрации и авторизации |
| Команда разработки | Получить понятные требования, пользовательские сценарии и ограничения MVP |

**Роли пользователей**

| **Роль** | **Описание** |
|---|---|
| Мастер | Основной пользователь системы: управляет профилем, услугами, расписанием, записями и клиентами |
| Клиент | Просматривает услуги, цены, свободные слоты, создаёт и отменяет свои записи |

## 6. Основной бизнес-процесс: онлайн-запись на услугу

Ключевой процесс MVP — самостоятельная онлайн-запись клиента на услугу через сайт Beauty Bliss.

В рамках процесса клиент выбирает категорию услуги, конкретную услугу, дату и свободный временной слот, вводит контактные данные и подтверждает запись. После этого система проверяет корректность данных и доступность выбранного слота, создаёт запись и отправляет уведомления клиенту и мастеру.

Детальное описание пользовательских сценариев представлено в папке [use-cases](./use-cases).

## 7. Прототипы экранов

Прототипы экранов подготовлены отдельными PDF-файлами и размещены в папке [prototypes](./prototypes).

Прототипы охватывают основные пользовательские зоны продукта:

### 1. Публичная часть сайта

Экраны, доступные клиенту без авторизации:

- главная страница
- список категорий услуг и услуг
- страница с ценами
- страница FAQ
- контактный блок

### 2. Сценарий онлайн-записи

Экраны, связанные с созданием записи:

- выбор категории услуги
- выбор конкретной услуги
- выбор даты и свободного времени
- ввод контактных данных
- подтверждение записи

### 3. Личный кабинет зарегистрированного клиента

Экраны для управления данными и записями клиента:

- мой профиль: просмотр, редактирование, удаление профиля
- мои записи: просмотр и отмена записи
- переход к новой записи

### 4. Личный кабинет мастера

Экраны для управления работой мастера:

- профиль мастера
- расписание
- список записей
- карточка клиента
