## US-01. Выбор процедуры для записи

**Связанный UC:** [UC-01. Онлайн-запись клиента на процедуру без регистрации](../use-cases/UC-01.booking.md)

`Как` клиент,  
`хочу` выбрать процедуру из каталога,  
`чтобы` записаться на нужную услугу.

**Критерии приемки:**

- Клиент видит список направлений процедур
- Клиент может выбрать направление
- Клиент видит процедуры выбранного направления
- Клиент может выбрать процедуру

## US-02. Ознакомление с процедурой

**Связанный UC:** [UC-01. Онлайн-запись клиента на процедуру без регистрации](../use-cases/UC-01.booking.md)

`Как` клиент,  
`хочу` ознакомиться с кратким описанием, стоимостью и длительностью процедуры,  
`чтобы` принять решение о записи.

**Критерии приемки:**

- Клиент видит карточку процедуры во время онлайн-записи
- В карточке процедуры отображаются название, краткое описание, стоимость и длительность процедуры

## US-03. Выбор даты и времени визита

**Связанный UC:** [UC-01. Онлайн-запись клиента на процедуру без регистрации](../use-cases/UC-01.booking.md)

`Как` клиент,  
`хочу` выбрать дату и время визита,  
`чтобы` спланировать свое время.

**Критерии приемки:**

- Клиент видит список доступных дат
- Клиент может выбрать дату визита
- Система отображает свободные временные слоты на выбранную дату
- Клиент может выбрать свободный временной слот
- Забронированный временной слот не отображается как доступный для бронирования

## US-04. Подтверждение записи

**Связанный UC:** [UC-01. Онлайн-запись клиента на процедуру без регистрации](../use-cases/UC-01.booking.md)

`Как` клиент,  
`хочу` проверить и подтвердить параметры записи,  
`чтобы` убедиться, что процедура, дата и время выбраны корректно.

**Критерии приемки:**

- Клиент видит выбранные параметры записи: процедуру, дату и время визита
- Клиент может подтвердить выбранные параметры записи
- После подтверждения система отображает форму контактных данных

## US-05. Ввод контактных данных

**Связанный UC:** [UC-01. Онлайн-запись клиента на процедуру без регистрации](../use-cases/UC-01.booking.md)

`Как` клиент,  
`хочу` ввести имя и номер телефона без регистрации,  
`чтобы` завершить запись на процедуру и получить информацию о визите.

**Критерии приемки:**

- Клиент видит форму ввода контактных данных
- Клиент может ввести имя и номер телефона
- Система не требует регистрации для отправки контактных данных
- Система сообщает об ошибке, если контактные данные заполнены некорректно
- После отправки корректных данных система создает запись

## US-06. Получение подтверждения записи

**Связанный UC:** [UC-01. Онлайн-запись клиента на процедуру без регистрации](../use-cases/UC-01.booking.md)

`Как` клиент,  
`хочу` получить подтверждение успешной записи,  
`чтобы` быть уверенным, что визит забронирован.

**Критерии приемки:**

- После отправки корректных контактных данных клиент видит подтверждение успешной записи
- В подтверждении отображаются параметры записи: направление и название процедуры, дата и время визита

## US-07. Связь с мастером

**Связанный UC:** не связан с отдельным UC, относится к общему сценарию просмотра сайта

`Как` клиент,  
`хочу` видеть доступные способы связи с мастером в футере сайта,  
`чтобы` быстро выбрать удобный канал для связи.

**Критерии приемки:**

- Клиент видит доступные способы связи в футере сайта: MAX, VK, email и телефон
- При нажатии на иконку MAX открывается канал связи мастера в MAX
- При нажатии на иконку VK открывается страница мастера во VK
- При нажатии на иконку email открывается создание письма на адрес мастера
- При нажатии на иконку телефона открывается набор номера мастера

## US-08. Авторизация мастера

**Связанный UC:** [UC-02. Авторизация мастера](../use-cases/UC-02.master-authorization.md)

`Как` мастер,  
`хочу` войти в личный кабинет,  
`чтобы` управлять процедурами, расписанием, профилем и записями.

**Критерии приемки:**

- Мастер видит форму авторизации
- Мастер может ввести логин и пароль
- Мастер может отправить данные для входа
- Если логин и пароль корректны, система авторизует мастера
- После успешной авторизации система открывает личный кабинет мастера
- Если логин или пароль некорректны, система сообщает об ошибке авторизации
- Если превышено количество попыток входа, система временно ограничивает повторные попытки
- Если мастер забыл пароль, система сообщает, что для восстановления доступа нужно обратиться в поддержку или к администратору
- Неавторизованный пользователь не получает доступ к личному кабинету мастера

## US-09. Управление процедурой

**Связанный UC:** [UC-03. Управление процедурами](../use-cases/UC-03.procedures-management.md)

`Как` мастер,  
`хочу` создавать и редактировать процедуры,  
`чтобы` клиенты видели актуальный список процедур, доступных для записи.

**Критерии приемки:**

- Мастер может создать новую процедуру
- Мастер может изменить название, описание, стоимость, длительность и статус процедуры
- Процедура со статусом "Доступна" отображается клиентам
- Процедура со статусом "Недоступна" не отображается клиентам

## US-10. Настройка расписания

**Связанный UC:** [UC-04. Настройка рабочего расписания](../use-cases/UC-04.schedule-settings.md)

`Как` мастер,  
`хочу` настроить рабочие дни, время работы и недоступные периоды,  
`чтобы` клиенты видели актуальное расписание и могли записываться только на доступное время.

**Критерии приемки:**

- Мастер может указать рабочие дни
- Мастер может указать время начала и окончания рабочего дня
- Мастер может добавить недоступный период
- Клиентам не отображаются слоты в недоступные периоды, а также до начала и после окончания рабочего дня

## US-11. Управление профилем мастера

**Связанный UC:** не связан с отдельным UC, относится к сценарию управления профилем мастера

`Как` мастер,  
`хочу` редактировать свои данные и доступные каналы связи,  
`чтобы` клиенты видели актуальную информацию и могли выбрать удобный способ связи.

**Критерии приемки:**

- Мастер может изменить своё имя
- Мастер может добавить канал связи
- Мастер может изменить значение канала связи
- Мастер может отключить канал связи
- Мастер может выбрать канал связи по умолчанию
- Клиент видит только активные каналы связи мастера в футере сайта
- Если канал связи не настроен или отключён, его иконка не отображается клиенту
