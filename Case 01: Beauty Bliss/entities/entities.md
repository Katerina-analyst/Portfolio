# Сущности предметной области

### Назначение сущностей

| **Сущность** | **Назначение** |
| ------------ | -------------- |
| Клиент | Хранит данные клиента, который записывается на процедуру |
| Мастер | Хранит данные мастера, который оказывает процедуры |
| Запись | Хранит данные о визите клиента на процедуру |
| Процедура | Хранит данные о предоставляемой процедуре |
| Тип процедуры | Хранит справочные данные о направлениях процедур |
| Слот | Хранит данные о временном интервале для записи: время начала, длительность и доступность |
| Расписание | Хранит график работы мастера |
| Недоступный период | Хранит информацию о периодах недоступности мастера |
| Уведомление | Хранит информацию об отправке уведомлений клиенту и мастеру |
| Тип уведомления | Хранит справочные данные о типах уведомлений |
| Тип канала связи | Хранит справочные данные о доступных типах каналов связи |
| Канал связи | Хранит контактные данные клиента или мастера для выбранного типа канала связи |
