# Сущности предметной области

### Назначение сущностей

| **Сущность** | **Назначение** |
| ------------ | -------------- |
| Пользователь | Хранит данные пользователя системы |
| Запись | Хранит данные о визите клиента на процедуру |
| Процедура | Хранит данные о процедуре мастера и её статусе доступности для онлайн-записи |
| Тип процедуры | Хранит справочные данные о направлениях процедур |
| Слот | Представляет временной интервал, доступный для онлайн-записи |
| Расписание | Хранит график работы мастера |
| Недоступный период | Хранит информацию о периодах недоступности мастера |
| Уведомление | Хранит информацию об отправке уведомлений клиенту и мастеру |
| Тип канала связи | Хранит справочные данные о доступных типах каналов связи |
| Канал связи | Хранит контактное значение пользователя для выбранного типа канала связи |

### Допущение по формированию слотов

Система формирует доступные слоты на основе:

- расписания мастера
- недоступных периодов мастера
- уже созданных записей
- длительности выбранной процедуры

Длительность процедуры задается в карточке процедуры.
При формировании слота система рассчитывает `end_time` как `start_time + duration` выбранной процедуры.
