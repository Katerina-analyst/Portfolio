# Основной бизнес-процесс

В разделе подробно описан основной бизнес-процесс: Онлайн-запись клиента на процедуру.

**Результат бизнес-процесса:**

- При успешном завершении клиент записан на выбранную процедуру, запись сохранена в системе, а клиенту и мастеру инициирована отправка уведомлений
- При неуспешном завершении запись не создается, выбранный временной интервал не блокируется, клиент оповещен о причине невозможности записи
