# Онлайн-запись в кабинет косметолога

## 1. О проекте

Веб-интерфейс проекта доступен по адресу:  
https://beauty-bliss.ru/


Статус проекта: MVP в разработке.
В репозитории представлена аналитическая документация и материалы проектирования. Пользовательский интерфейс реализован, серверная часть находится в разработке.

Система представляет собой веб-сервис для управления приемами и онлайн-записи клиентов в кабинет косметолога. Клиент может без регистрации записаться на процедуру, а затем просмотреть или отменить запись по персональной ссылке. Косметолог через личный кабинет управляет процедурами, расписанием, недоступными периодами, контактными данными и записями клиентов. Система автоматически формирует доступные даты и временные слоты на основе расписания, длительности процедуры, существующих записей и недоступных периодов, а также инициирует отправку уведомлений о событиях записи и напоминаний о предстоящем визите.

Требования к системе подробно описаны в [Спецификации требований](./requirements/srs.md).

## 2. Проблема и цель проекта

До внедрения системы косметолог ведет расписание и записи вручную через звонки, сообщения и календарь. Это требует постоянного участия косметолога, увеличивает риск потери заявок и возникновения накладок в расписании.

Клиенту необходимо связываться с косметологом и ждать ответа, чтобы узнать доступное время, записаться на процедуру или отменить запись.

Цель MVP - предоставить клиенту возможность самостоятельно записаться на процедуру и отменить свою запись, а также сократить объем ручной работы косметолога при ведении расписания и записей.

## 4. Инструменты и методики

В работе над проектом использовала:  
- BPMN 2.0 - для моделирования основного бизнес-процесса TO BE
- UML - для моделирования взаимодействий клиента и сервиса, компонентов системы и с внешними системами
- User Story и Use Case - для описания пользовательских потребностей и сценариев
- SQL и PostgreSQL - для проектирования структуры базы данных, подготовки тестовых данных и выполнения запросов
- Balsamiq - для подготовки прототипов экранов пользовательского интерфейса
- Draw.io и StormBPMN - для построения диаграмм
- OpenAPI (Swagger) - для описания REST API
- Markdown - для ведения проектной документации
