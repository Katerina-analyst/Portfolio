# Онлайн-запись в кабинет косметолога

## 1. О проекте

Система представляет собой веб-сайт, предназначенный для полной автоматизации взаимодействия между независимым частным мастером и его клиентами. Проект решает проблему ручного администрирования, полностью заменяя ручную переписку в мессенджерах, звонки и ведение расписания в календаре на автономную цифровую систему управления визитами. Для мастера система работает как умный календарь: она автоматически формирует свободные временные слоты на основе его графика,  фиксирует бронирования, исключает накладки в календаре, самостоятельно рассылает клиентам уведомления и напоминания о предстоящих визитах, уведомляет мастера о новых записях и отменах записей клиентами. Для клиента сервис работает как круглосуточный сайт, где можно быстро изучить процедуры и забронировать свободное время без обязательной регистрации.

Требования к системе подробно описаны в [Спецификации требований](./requirements/srs.md).

## 2. Проблема и цель проекта

До внедрения системы мастер ведет расписание и записи вручную через звонки, сообщения и календарь. Это требует постоянного участия мастера, увеличивает риск потери заявок и возникновения накладок в расписании. Клиенту необходимо связываться с мастером и ждать ответа, чтобы узнать доступное время, записаться на процедуру или отменить запись.

Цель MVP - предоставить клиенту возможность самостоятельно записаться на процедуру или отменить свою запись и сократить объем ручной работы мастера при ведении расписания и записей.

## 6. Инструменты и методы

В своей работе на проекте я использовала:  
- BPMN - для моделирования TO BE основного бизнес-процесса
- UML - для описания вариантов использования и взаимодействия с системой
- Markdown - для подготовки аналитической документации
- SQL - для проектирования структуры базы данных и примеров запросов
- User Story и Use Case - для описания пользовательских требований и сценариев использования
- MoSCoW - для приоритизации требований
- Balsamiq - для подготовки прототипов пользовательского интерфейса
- Draw.io, Stormbpmn - для построения диаграмм
- PostgreSQL - запуска схемы БД, наполнение тестовыми данными и выполнение запросов к БД
